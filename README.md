# 📚 Book Notes Project

A web application where users can save the books they have read, write notes, and search through their collection.

## Features

- ➕ Add new books
- 🔍 Search books by title
- 📝 Save personal notes
- 🖼️ Automatic book covers from Open Library API
- 🗄️ PostgreSQL database

## Technologies

- Node.js
- Express.js
- PostgreSQL
- EJS
- Bootstrap 5
- Axios
- Open Library API

## Installation

```bash
npm install
```

Create a `.env` file:

```env
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5433
DB_NAME=books
```

Run the project:

```bash
node index.js
```
